# วิธีตั้งค่า Discord Webhook สำหรับแจ้งเตือนราคาหุ้น

คู่มือนี้สำหรับคนที่ไม่เคยใช้ Discord มาก่อน ใช้เวลาประมาณ 10 นาที

**Webhook คืออะไร:** มันคือ "ที่อยู่" (URL) ของห้องแชตใน Discord ใครมี URL นี้ก็ส่งข้อความเข้าห้องนั้นได้
แอปของเราจะใช้ URL นี้ส่งข้อความแจ้งเตือนราคาหุ้นเข้ามาในห้องที่คุณสร้างไว้
ส่วนตัวคุณจะได้รับการแจ้งเตือนผ่านแอป Discord บนมือถือหรือคอม

---

## ขั้นที่ 1: สมัครบัญชี Discord

1. เข้า https://discord.com แล้วกด **Login** (มุมขวาบน) จากนั้นกด **Register**
2. กรอกอีเมล ชื่อที่แสดง ชื่อผู้ใช้ รหัสผ่าน และวันเกิด แล้วกด **Continue**
3. เปิดอีเมลแล้วกดลิงก์ยืนยัน (**Verify Email**)
4. (แนะนำ) ติดตั้งแอป Discord บนมือถือ (App Store / Google Play) แล้วล็อกอินด้วยบัญชีเดียวกัน
   จะได้รับแจ้งเตือนเด้งบนมือถือ

> ใช้งานผ่านเว็บเบราว์เซอร์ที่ https://discord.com/app ก็ได้ ไม่ต้องติดตั้งโปรแกรมบนคอม

## ขั้นที่ 2: สร้างเซิร์ฟเวอร์ส่วนตัว

"เซิร์ฟเวอร์" ใน Discord คือกลุ่มแชตกลุ่มหนึ่ง เราจะสร้างกลุ่มที่มีแค่คุณคนเดียว

1. ที่แถบซ้ายสุด กดปุ่ม **+** (Add a Server)
2. เลือก **Create My Own**
3. เลือก **For me and my friends**
4. ตั้งชื่อ เช่น `หุ้นของฉัน` แล้วกด **Create**

## ขั้นที่ 3: สร้างห้อง (channel) สำหรับแจ้งเตือน

ใช้ห้อง `#general` ที่มีอยู่แล้วก็ได้ แต่แยกห้องไว้จะดูง่ายกว่า

1. ที่หัวข้อ **TEXT CHANNELS** กดปุ่ม **+** (Create Channel)
2. เลือก **Text** แล้วตั้งชื่อ เช่น `แจ้งเตือนหุ้น` (หรือ `stock-alerts`)
3. กด **Create Channel**

## ขั้นที่ 4: สร้าง Webhook และคัดลอก URL

1. เอาเมาส์ไปชี้ที่ห้อง `แจ้งเตือนหุ้น` แล้วกดรูป **เฟือง ⚙️** (Edit Channel)
2. เมนูซ้าย เลือก **Integrations**
3. กด **Create Webhook** (ถ้าเคยมีแล้วจะเป็นปุ่ม **View Webhooks** → **New Webhook**)
4. จะมี webhook ชื่อแปลก ๆ เช่น `Captain Hook` ขึ้นมา กดที่มันเพื่อแก้
   - **Name:** เปลี่ยนเป็น `Shariah Stock Watch` (ชื่อนี้จะแสดงเป็นผู้ส่งข้อความ)
   - **Channel:** ตรวจว่าเป็นห้อง `แจ้งเตือนหุ้น`
5. กด **Copy Webhook URL**
6. กด **Save Changes** ที่แถบล่าง (ถ้ามี)

URL ที่ได้จะหน้าตาประมาณนี้:

```
https://discord.com/api/webhooks/123456789012345678/AbCdEf...ยาวมาก...
```

> ⚠️ **URL นี้เป็นความลับ** ใครได้ไปก็ส่งข้อความเข้าห้องคุณได้
> ห้ามโพสต์ในที่สาธารณะหรือ commit ขึ้น git ถ้าหลุด ให้กลับมาที่หน้านี้แล้วกด **Delete Webhook** แล้วสร้างใหม่

> ขั้นนี้ทำบนมือถือได้เหมือนกัน แต่ทำบนคอมจะคัดลอก URL ไปวางในไฟล์ได้ง่ายกว่า

## ขั้นที่ 5: ใส่ URL ลงในโปรเจกต์

1. เปิดไฟล์ `.env` ที่โฟลเดอร์หลักของโปรเจกต์ (`D:\Claude-code\Halal_Stocks\.env`)
2. วาง URL ต่อท้าย `DISCORD_WEBHOOK_URL=` โดยไม่ต้องมีเครื่องหมายคำพูดและไม่มีช่องว่าง

```env
PORT=4000
CLIENT_ORIGIN=http://localhost:5173
DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/123456789012345678/AbCdEf...
```

3. บันทึกไฟล์ ถ้าเปิด `npm run dev` ค้างไว้ ให้กด Ctrl+C แล้วรันใหม่

> ไฟล์ `.env` ถูกตั้งไว้ใน `.gitignore` แล้ว จึงไม่ถูก commit ขึ้น git

## ขั้นที่ 6: ทดสอบว่า Webhook ใช้ได้

เปิด PowerShell แล้ววางคำสั่งนี้ โดยเปลี่ยน `วาง_URL_ที่นี่` เป็น URL ของคุณ (เก็บเครื่องหมาย `'` ไว้ทั้งสองข้าง)

```powershell
Invoke-RestMethod -Method Post -ContentType 'application/json' -Uri 'วาง_URL_ที่นี่' -Body '{"content":"Hello from Shariah Stock Watch!"}'
```

ถ้าสำเร็จ จะไม่มีอะไรแสดงใน PowerShell แต่ในห้อง `แจ้งเตือนหุ้น` จะมีข้อความ **Hello from Shariah Stock Watch!** เด้งขึ้นมา

ถ้าไม่สำเร็จ ดูหัวข้อ [แก้ปัญหา](#แก้ปัญหา)

> เมื่อระบบแจ้งเตือนเสร็จแล้ว จะมีปุ่ม **ส่งข้อความทดสอบ** ในหน้าเว็บด้วย ไม่ต้องใช้คำสั่งนี้อีก

## ขั้นที่ 7: ตั้งให้มือถือเด้งแจ้งเตือน

ในแอป Discord บนมือถือ

1. เปิดเซิร์ฟเวอร์ `หุ้นของฉัน` แล้วกดค้างที่ห้อง `แจ้งเตือนหุ้น`
2. เลือก **Notification Settings** (หรือ **Notifications**)
3. เลือก **All Messages**

และตรวจว่าในการตั้งค่าของมือถือ (Settings → Notifications → Discord) เปิดให้แอป Discord แจ้งเตือนได้

> ถ้าไม่อยากให้ห้องอื่นเด้ง ให้ตั้งเฉพาะห้องนี้เป็น All Messages ส่วนห้องอื่นเป็น Nothing หรือ Only @mentions

## แก้ปัญหา

| อาการ                                                    | สาเหตุ / วิธีแก้                                                                                                        |
| -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| ไม่เห็นเมนู **Integrations** หรือปุ่ม Create Webhook     | ต้องเป็นเจ้าของเซิร์ฟเวอร์ (หรือมีสิทธิ์ Manage Webhooks) ให้ใช้เซิร์ฟเวอร์ที่คุณสร้างเองในขั้นที่ 2                    |
| PowerShell ขึ้น `(404) Not Found` หรือ `Unknown Webhook` | URL ผิด, คัดลอกมาไม่ครบ หรือ webhook ถูกลบไปแล้ว ให้กด Copy Webhook URL ใหม่                                            |
| PowerShell ขึ้น `(400) Bad Request`                      | คำสั่งพิมพ์ผิด โดยเฉพาะเครื่องหมาย `'` และ `"` ให้คัดลอกคำสั่งไปทั้งบรรทัด                                              |
| PowerShell ขึ้น `(429) Too Many Requests`                | ส่งถี่เกินไป รอสักครู่แล้วลองใหม่                                                                                       |
| ข้อความเข้าห้องแต่มือถือไม่เด้ง                          | ทำขั้นที่ 7 ใหม่ และตรวจว่าไม่ได้เปิดโหมดห้ามรบกวน (Do Not Disturb) ใน Discord หรือในมือถือ                             |
| หน้าเว็บบอกว่ายังไม่ได้ตั้ง webhook                      | ตรวจว่าใส่ใน `.env` ที่โฟลเดอร์หลัก (ไม่ใช่ `server/` หรือ `client/`), ชื่อตัวแปรสะกดถูก และรีสตาร์ต `npm run dev` แล้ว |
