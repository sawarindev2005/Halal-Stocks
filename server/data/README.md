# shariah_list.json — รายชื่อหุ้นชาริอะห์

| ตลาด | ที่มา                                                                                                                                                                                                   |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| US   | บทความ [สรุปรายชื่อ ETF ฮาลาล ที่สามารถลงทุนได้ในแอป Dime!](https://dime.co.th/th/articles/halal-etf-list) (เผยแพร่ 21 ก.พ. 2568, ข้อมูล ณ 10 ก.พ. 2568 — Dime อ้างอิง Zoya, Musaffa และเว็บไซต์กองทุน) |
| TH   | ⚠️ **ยังเป็นข้อมูลตัวอย่าง (SAMPLE DATA)** — ไม่ใช่ผลคัดกรองจริง                                                                                                                                        |

- **ETF (16 ตัว, sector = ETF)** — ทุกกองที่บทความจัดว่าฮาลาล 7 กองติดตามดัชนีชาริอะห์ (SPUS, HLAL, SPSK, SPRE, SPTE, SPWO, UMMA) อีก 9 กองเป็น ETF รายอุตสาหกรรม
- **หุ้นรายตัว** — เฉพาะหุ้นที่บทความระบุว่าเป็น 5 อันดับแรกของ 7 กองดัชนีชาริอะห์ (ฟิลด์ `screenedBy` บอกว่าถือโดยกองใด)
  ไม่ได้ใส่หุ้นในกอง ETF รายอุตสาหกรรม เพราะหุ้นเหล่านั้นไม่ได้ผ่านการคัดกรองชาริอะห์รายตัว
- ข้ามไป: Goodman Group, Meituan, Infineon (ไม่มี ticker ในตลาดสหรัฐฯ) และ AvalonBay (AVB — ควบรวมเป็น Vivmark Residential ส.ค. 2569 เลิกซื้อขายแล้ว)
- หุ้นที่กองถือเปลี่ยนได้ตลอด และสถานะชาริอะห์ของแต่ละบริษัทเปลี่ยนได้ ควรตรวจกับ Zoya / Musaffa หรือเว็บกองทุนก่อนตัดสินใจ

## รูปแบบข้อมูล

```json
{
  "_notice": "ข้อความเตือน (เซิร์ฟเวอร์ไม่อ่านฟิลด์นี้)",
  "stocks": [
    {
      "symbol": "ADVANC.BK",
      "name": "Advanced Info Service",
      "market": "TH",
      "sector": "Telecommunications",
      "screenedBy": "ชื่อแหล่งที่คัดกรอง",
      "updatedAt": "2026-01-01"
    }
  ]
}
```

| ฟิลด์        | คำอธิบาย                                                                                                               |
| ------------ | ---------------------------------------------------------------------------------------------------------------------- |
| `symbol`     | สัญลักษณ์ตาม Yahoo Finance — หุ้นไทยต้องลงท้ายด้วย `.BK` (เช่น `ADVANC.BK`), หุ้นสหรัฐฯ ใช้ ticker ตรง ๆ (เช่น `AAPL`) |
| `name`       | ชื่อบริษัท                                                                                                             |
| `market`     | `TH` หรือ `US`                                                                                                         |
| `sector`     | กลุ่มอุตสาหกรรม (ใช้ในตัวกรองหน้า Dashboard)                                                                           |
| `screenedBy` | แหล่ง/ผู้ที่คัดกรองสถานะชาริอะห์                                                                                       |
| `updatedAt`  | วันที่ยืนยันสถานะล่าสุด รูปแบบ `YYYY-MM-DD`                                                                            |

เซิร์ฟเวอร์ตรวจไฟล์ด้วย zod ตอนโหลด ถ้ารูปแบบผิด เซิร์ฟเวอร์จะแจ้ง error พร้อมบอกว่าฟิลด์ไหนผิด
หลังแก้ไฟล์ให้รีสตาร์ตเซิร์ฟเวอร์ (โหมด `dev` จะรีโหลดให้อัตโนมัติเฉพาะไฟล์ใน `src/` เท่านั้น)
