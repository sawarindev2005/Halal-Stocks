# news/ — สรุปข่าวประจำวันส่งเข้า Discord

ทุกวัน 07:00 น. (เวลาไทย) ระบบจะดึงข่าวจาก RSS ให้ AI (Claude หรือ Gemini) สรุปเป็นภาษาไทย หมวดละ 2–3 ข่าว พร้อมลิงก์ต้นทาง แล้วส่งเข้า Discord
ส่วนนี้แยกจากระบบแจ้งเตือนราคา (`alerts/`) โดยใช้ร่วมกันแค่ตัวส่ง Discord (`createDiscordNotifier`), ฐานข้อมูล และรายชื่อหุ้น

| ไฟล์                      | หน้าที่                                                                        |
| ------------------------- | ------------------------------------------------------------------------------ |
| `feeds.ts`                | รายชื่อแหล่งข่าว RSS แยกหมวด — **แก้ไฟล์นี้ถ้าอยากเพิ่ม/ลบแหล่งข่าว**          |
| `feedFetcher.ts`          | ดึงและอ่าน RSS, เอาเฉพาะข่าว 24 ชม. ล่าสุด, ฟีดไหนล่มก็ข้ามไป                  |
| `summarizer.ts`           | สรุปด้วย Claude + prompt/schema ที่ใช้ร่วมกัน + `headlinesOnly()` แผนสำรอง     |
| `geminiSummarizer.ts`     | สรุปด้วย Gemini (prompt และกติกาเดียวกับ Claude)                               |
| `digestMessage.ts`        | จัดข้อความ "📰 สรุปข่าวประจำวัน \| วันที่" แบ่งข้อความละไม่เกิน 2,000 ตัวอักษร |
| `digestJob.ts`            | รวมทุกขั้น: ดึงข่าว → ตัดข่าวที่เคยส่ง → สรุป → ส่ง → บันทึกประวัติ            |
| `newsRepository.ts`       | เก็บประวัติข่าวที่ส่งแล้ว (SQLite) — `mysqlNewsRepository.ts` คือแบบ MySQL     |
| `scheduler.ts`            | ตั้งเวลาด้วย node-cron พร้อมเขตเวลา `Asia/Bangkok` + ระบบส่งย้อนหลัง           |
| `index.ts` / `runOnce.ts` | ประกอบระบบจาก config / โหมดทดสอบรันทันที                                       |

## กันพลาด

- **ฟีดดึงไม่ได้** → ข้ามไปฟีดอื่น (ลองใหม่ 1 ครั้งถ้าโดน 429/5xx) และแสดงใน log
- **AI สรุปไม่ได้** (ไม่มี API key, API ล่ม, ตอบผิดรูปแบบ) → ส่งหัวข้อข่าว + ลิงก์แทน พร้อมหมายเหตุในข้อความ
- **Claude แต่งลิงก์เองไม่ได้** — Claude เลือกข่าวด้วยรหัส (`a1`, `a2`, …) แล้วโค้ดใส่ลิงก์จริงจาก RSS ให้
- **ไม่ส่งซ้ำ** — ลิงก์ที่ส่งแล้วถูกบันทึกในตาราง `sent_news` (เก็บ 14 วัน) วันถัดไปจะข้ามข่าวเหล่านี้
- **พลาดเวลา 07:00** (คอม Sleep, server ปิดอยู่) → ส่งย้อนหลังทันทีที่กลับมาทำงานในวันเดียวกัน: server เช็กทุก 10 นาที (และ 1 นาทีหลังเปิด) ว่าวันนี้ส่งแล้วหรือยัง จากตาราง `news_runs` ถ้าส่งย้อนหลังไม่สำเร็จจะลองใหม่ทุก 1 ชั่วโมง — รัน `news:once` เองก็นับว่าวันนั้นส่งแล้ว (ยกเว้น `--dry-run`)
- **ส่ง Discord ไม่สำเร็จ** → ไม่บันทึกว่าส่งแล้ว รอบหน้าจะลองใหม่

## ทดสอบโดยไม่ต้องรอ 07:00

```bash
npm --prefix server run news:once -- --dry-run   # แสดงข้อความในหน้าจอ ไม่ส่ง ไม่บันทึก
npm --prefix server run news:once                # ส่งเข้า Discord จริง 1 รอบ
```

ใน Docker: `docker compose run --rm server npm run news:once -- --dry-run`

## เลือก AI ที่ใช้สรุป

| ค่าย   | ตั้งค่าใน `.env`                                          | โมเดลเริ่มต้น                                   |
| ------ | --------------------------------------------------------- | ----------------------------------------------- |
| Gemini | `GEMINI_API_KEY=...` (จาก https://aistudio.google.com)    | `gemini-3.5-flash` (เปลี่ยนด้วย `GEMINI_MODEL`) |
| Claude | `ANTHROPIC_API_KEY=...` (จาก https://platform.claude.com) | `claude-opus-5-5` (เปลี่ยนด้วย `NEWS_MODEL`)    |

ใส่ค่ายเดียวก็พอ ถ้าใส่ทั้งคู่จะใช้ Claude ก่อน หรือบังคับด้วย `NEWS_AI_PROVIDER=gemini` / `claude`
ทั้งสองค่ายใช้ prompt, รูปแบบคำตอบ และกติกาเดียวกัน (หมวดละ 2–3 ข่าว, เลือกข่าวด้วยรหัส จึงแต่งลิงก์ไม่ได้)
